# セッション名に状態の絵文字を付ける

並行して動かしているセッションのうち、どれが自分の番でどれが作業中かを、サイドバーのセッション名だけでわかるようにする。サイドバーの「実行中」「入力待ち」「失敗」のドットではわからない**作業の段階**を、名前の先頭の絵文字で表す。

積極的に使う。デスクトップアプリでは、作業の大小にかかわらず最初のターンで（最初のツール呼び出しと同じメッセージで）絵文字を付け、このセッションが終わるまでここのルールで更新し続ける。

## 絵文字

| 絵文字 | 状態 | 付けるとき |
| --- | --- | --- |
| 📝 | 計画中 | plan モードで計画を立てているとき（`ExitPlanMode` が承認されるまで） |
| 🔍 | 調査・設計中 | コードや資料を読み始めたとき、設計を考えているとき |
| 🛠️ | 実装中 | ファイルの編集を始めたとき |
| 🧪 | テスト・レビュー中 | テスト・型チェック・リンター・ビルドや、codex-impl-review などのレビューを動かすとき |
| ❓ | 判断待ち | 質問・選択・承認（コミット・push・PR 作成など）を求めてターンを終えるとき |
| ⏳ | 外部待ち | CI の実行、ほかのセッションやバックグラウンドのタスクの完了を待っていて、終われば Claude が続きを進めるとき |
| 🚀 | PR 作成済み・マージ待ち | PR を作り、Claude の作業は終わって、人のレビューやマージを待つだけのとき |
| 🔥 | ブロック・失敗 | エラー・権限・環境の不足などで、ユーザーが何かを直さないと先に進めないとき |
| 🎉 | 完了 | 依頼された作業を終え、ユーザーが判断することも残っていないとき |

迷いやすい組み合わせ:

- **❓ と 🔥**: 選べば進めるなら ❓、ユーザーが何かを直さないと進めないなら 🔥。
- **⏳ と 🚀**: 待ちが終わったら Claude が続きを進めるなら ⏳、Claude の作業が終わって人のレビューやマージを待つだけなら 🚀。
- **ターンの終わりに複数当てはまるとき**: 🔥 → ❓ → ⏳ → 🚀 → 🎉 の順で先にあるものを選ぶ（ユーザーが動く必要があるものを優先する）。

**表のどれにも当てはまらないとき**は、その状態をいちばんよく表す絵文字を自分で選んで付ける（例: ドキュメントを書いている → ✍️、デプロイ中 → 📦、データを移行している → 🚚）。選ぶときは次を守る。

- 表の絵文字と見分けやすいものにする（表の絵文字と似た形や意味のものは避ける）。
- 1 文字の絵文字にする（複数の絵文字をつないだ合成絵文字は、環境によって崩れるため使わない）。
- 当てはまる状態が表にあるなら、表の絵文字を優先する。表にない絵文字は、本当に当てはまらないときだけ使う。

## 更新するタイミング

- **段階が変わったときだけ**更新する。手順ごとや、同じ段階の中では変えない（ツール呼び出しを増やさず、サイドバーをちらつかせないため）。
- **ターンの終わりには必ず確認する**。`wrap_up` を呼ぶ前に、上の表で 🔥 / ❓ / ⏳ / 🚀 / 🎉 のどれかに合わせる。作業の途中の絵文字（🔍 / 🛠️ / 🧪）のままターンを終えない。
- 短い質問に答えるだけのターンでも、名前にまだ絵文字がなければ付ける（答え終わったら 🎉、返事を待つなら ❓）。
- 前のターンで 🎉 や ❓ にしたあと、ユーザーが新しい依頼や返事をしたら、取りかかる作業の絵文字に戻す。

## 更新のしかた

1. `mcp__ccd_session_mgmt__get_session`（`session_id: "self"`）で今のタイトルを取る。ツールが読み込まれていなければ、ToolSearch で `select:mcp__ccd_session_mgmt__get_session,mcp__ccd_session_mgmt__set_session_title` を読み込む。
2. タイトルの先頭が、上の表の絵文字か、このスキルで前に付けた絵文字（表にない絵文字を選んだ場合）に続く「 ｜」（半角スペースと全角の縦棒。以前の形の「 - 」や半角スペースだけのものも含む）なら、それを取り除く。残りを元のタイトルとする。ユーザーがもともとタイトルの先頭に付けていた絵文字は取り除かない。
3. 付けたい絵文字がすでに付いていれば何もしない。
4. `mcp__ccd_session_mgmt__set_session_title`（`session_id: "self"`、`title: "<絵文字> ｜<元のタイトル>"`、例: `🛠️ ｜CSV エクスポートの追加`）で変える。元のタイトルの文言は変えない。

## 守ること

- 変えるのは**このセッションの名前だけ**。ほかのセッションの名前は変えない。
- 名前を変えたことはユーザーに報告しない（報告や recap に書かない）。
- 変更を断られたとき（ユーザーがつけたタイトルで承認を拒否されたときや、無人のセッションで断られたとき）は、このセッションでは以後名前を変えない。何度も確認を出さない。
- サブエージェントの中からは呼ばない（サブエージェントは自分が動いているセッションの名前を変えられない）。
- `mcp__ccd_session_mgmt__*` のツールがない環境（ターミナルの Claude Code など）では何もしない。
